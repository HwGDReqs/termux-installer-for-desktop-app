# Termux Installer for HwGDReqs Desktop App

An interactive script to install and run the desktop version of HwGDReqs on Android using Termux.

## Prerequisites

1. Install **[Termux](https://github.com/termux/termux-app/releases)** (from GitHub Releases or F-Droid).
2. Install **[Termux:X11](https://github.com/termux/termux-x11/releases)** (the installer can also download the APK for you if you don't have it yet).

## Installation

Open Termux and run the following command to download and run the interactive installer:

```bash
curl -sLO https://raw.githubusercontent.com/HwGDReqs/termux-installer-for-desktop-app/refs/heads/main/install-hwgdreqs.bash && bash install-hwgdreqs.bash
```

Follow the prompts on your screen to complete the setup.

## Usage

Once installed, launch the application anytime by running:

```bash
run-hwgdreqs
```
